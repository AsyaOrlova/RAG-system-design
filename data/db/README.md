# Corpus-Level Features

`data/db/summary.csv` is generated by the `src/domain_features/build_db_summary.py` script. For each `data/db/<dataset>/` subdirectory, the script takes the current pair of `articles_*.csv` and `chunks_*.csv` files, then writes one row per dataset to the resulting table.

## Sources

- `articles_*.csv`: `article_key`, `md`; `md` is treated as the main article text.
- `chunks_*.csv`: `article_key`, `embedding`; chunk embeddings are averaged per article, then the document embedding is L2-normalized.

## Columns

- `dataset`, `articles_file`, `chunks_file`: the dataset identifier and the file names used to compute the metrics.
- `num_documents`: the number of articles in `articles_*.csv`.
- `documents_with_embeddings`: the number of articles for which at least one valid embedding could be collected.

### Corpus Size

- `avg_doc_length`, `std_doc_length`, `total_corpus_size`: the average article length, standard deviation, and total corpus size in tokens; tokens are produced with `scispaCy` (`en_core_sci_sm`) without spaces or punctuation.
- `avg_doc_length_chars`, `std_doc_length_chars`, `total_corpus_size_chars`: the same metrics in characters, computed with `len(md)`.

### Structure

- `table_density`: the share of documents where at least one table was found; markdown tables and HTML `<table>` elements are detected.
- `avg_tables_per_doc`: the average number of detected tables per document.
- `figure_density`: the share of documents with figures; `Figure/Fig.` captions and non-artifact markdown/HTML images are used.
- `avg_figures_per_doc`: the average number of figures per document according to the same counter.
- `avg_sections_per_doc`: the average number of markdown headings after filtering out service and artifact headings.
- `avg_references_count`: the average number of references in the `References/Reference/Bibliography` section; if there is no explicit numbering, DOI mentions or paragraphs are used as a fallback.

### Linguistics

- `avg_sentence_length`: for each article, sentences are extracted with `nltk.sent_tokenize`, then the average sentence length is computed in scispaCy tokens; at the dataset level, these article-level values are averaged.
- `vocabulary_size`: the size of the set of unique corpus lemmas after tokenization and lemmatization with `scispaCy`.
- `technical_term_density`: for each article, entity spans are taken from `en_ner_bionlp13cg_md`; formula-like spans are excluded, then the share of alphabetic term tokens among regular word tokens in the article is computed.
- `chemical_name_density`: the share of tokens included in `CHEMICAL` entities from `en_ner_bc5cdr_md`, excluding formula-like tokens.
- `chemical_formula_density`: the share of formula-like tokens among the article's lexical tokens; computed with a regex heuristic over tokens.
- `formula_density`: the share of article characters occupied by LaTeX fragments (`$...$`, `\(...\)`, `\[...\]`, LaTeX commands); at the dataset level, this is averaged across articles.

### Embeddings

- `embedding_variance`: the average coordinate variance of L2-normalized document embeddings.
- `avg_pairwise_similarity`: the average cosine similarity across all unique document pairs.
- `embedding_cluster_count`: the number of clusters determined by the elbow heuristic on `KMeans`.
- `embedding_silhouette_score`: the silhouette score for the same `KMeans` partition selected in `embedding_cluster_count`; values closer to `1` indicate better-separated clusters, values near `0` indicate weak separation, and negative values indicate poor partitioning.
